# MoonlightLG 1.1.03U — star spacing

The Apollo connection field uses 90 stars instead of 140, reducing visual density
by about 36%. Positions still cover the same canvas and retain deterministic
sideways motion, depth and slowdown on reaching the moon. This is a drawing-only
adjustment; the native buttons, flight/orbit, connection gate and stream window
ownership are unchanged.

Version: 1.1.03U, internal build 32. Validation pending. U app download links remain
owner-only. Live-host handoff and physical Intel acceptance require the owner's Mac.
